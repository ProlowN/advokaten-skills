# Advokaten skills

Agent skills som ger din AI-agent kunskap om svensk vardagsjuridik. Katalogen finns på [advokaten.ai](https://advokaten.ai).

> Under arbete. Skillsen är inte publicerade ännu.

## Installera

När repot är publicerat:

```bash
npx skills add ProlowN/advokaten-skills --skill inkomstdeklaration
```

Du behöver Node.js 22.20 eller senare och en agent som stöder Agent Skills, till exempel Claude Code, Codex eller Cursor.

## Skills

| Skill | Beskrivning | Status |
|---|---|---|
| [inkomstdeklaration](skills/inkomstdeklaration/SKILL.md) | Granska och fyll i Inkomstdeklaration 1 | Under arbete: punkt 1–3 (tjänst) klar |

## Ingen juridisk rådgivning

Skills ger information och struktur, inte juridisk rådgivning. Kontrollera alltid mot källorna och ta hjälp av en jurist eller Skatteverket när mycket står på spel.
